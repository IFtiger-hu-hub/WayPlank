0. Crashes during test
   [ko->ok] : Crashed during icon rearranging:
   Fixed a SIGSEGV (SEGV_MAPERR) crash during icon reordering caused by a use-after-free
   in __lambda94_ via deprecated Gdk.threads_add_timeout.
   The 750 ms long-press timer was not cancelled on mouse motion, attempting to trigger
   a context menu while a drag grab was in progress.
   Resolved by switching to GLib.Timeout.add with safe closure management and immediately
   cancelling the timer on pointer motion and drag start.

        Observed empty between separator situation with no unpinned running apps.
        Fixed phantom separator gap by ensuring unpinned apps are only retained as transient
        items if they actually have active GUI windows on the compositor (not idle background daemons).
        Orphan transient items with 0 windows are cleanly pruned during separator maintenance,
        and drag reordering distinguishes the trash separator from transient dividers.
   [ok] 1.5 Drag-Off Removal (Poof): Drag pinned icon away from dock -> poof animation

        Resolved active window detection by checking Mutter MRU tab list (excluding docks) so clicking

         The dock stays between two displays (primary and the one on the right), if changed monitor nothing happens.

          close actions dispatched in a rapid loop are received and executed. In
          KWin script, invoked target.closeWindow() with
          workspace.closeWindow(target) fallback.
   [ko->ok] 2.9 Window List Selection: Right-click app with 2+ windows -> click window title in list brings that window to front:

          minimized windows, or windows on other virtual desktops.
        - SOLVED: In KWin script applyWindowCommand, switched client lookup from
          workspace.stackingOrder (which omits minimized windows and windows on
          other workspaces) to getAllWindows(). Added automatic desktop
          switching via switchToDesktopIfNeeded prior to window activation so
          clicking a window on another desktop automatically switches to its
          virtual desktop and focuses it.
