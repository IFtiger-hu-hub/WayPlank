PHASE 1: MILESTONE V0.1.0 (2026-09-19) - ARCHITECTURE DECOUPLING & BASELINE
================================================================================
Summary: Excised upstream plank-0.11.89 legacy Autotools and X11 build pipeline
(112,000+ lines removed), migrated namespace to wayplank, and established
initial Wayland bare-launch display stubs and fast build scripts.

   [ko->ok] 1.1 Upstream Autotools Breakage & Legacy X11 Build Bloat:
        - BUG: Upstream plank-0.11.89 relied on obsolete GNU Autotools pipeline
          (configure.ac, Makefile.am, broken m4 macros, obsolete gmock tests)
          that failed to compile against modern GCC/Vala without X11 libraries.
        - SOLVED: Purged configure.ac, Makefile.in, autogen.sh, aclocal.m4, and
          300+ legacy po/ catalogs (over 112,600 lines excised). Created fast,
          direct compilation scripts (BuildBin.sh and BuildDeb.sh) using valac.
   [ko->ok] 1.2 Legacy Namespace Collisions & Hardcoded Plank Paths:
        - BUG: Hardcoded "plank" schemas, D-Bus interfaces, and file paths
          collided with host distribution installations of legacy Plank.
        - SOLVED: Executed complete namespace migration from Plank to Wayplank
          across all Vala modules, GSettings schemas, and binary output targets.
   [ko->ok] 1.3 Display Server Startup Lockout on Non-X11 Sessions:
        - BUG: AbstractMain forcefully exited with error if GDK_BACKEND was not
          explicitly x11, preventing the dock from starting on Wayland.
        - SOLVED: Excised hardcoded X11 display checks in AbstractMain.vala and
          introduced early Wayland display connection stubs.
   [ko->ok] 1.4 GResource Embedded Asset Compilation Failure:
        - BUG: UI definitions, themes, and icons were scattered across dynamic
          filesystem paths, leading to missing asset runtime crashes.
        - SOLVED: Bundled all internal schemas and SVG icons into a monolithic
          GResource bundle (plank.gresource.xml) compiled directly into C.

PHASE 2: MILESTONE V0.2.0 (2026-09-22) - NATIVE WAYLAND & GTK LAYER SHELL
================================================================================
Summary: Transformed dock surface from legacy X11 top-level window with screen
struts into a native Wayland layer surface via GTK Layer Shell, purged X11
strut logic, and introduced procfs process scanner for window tracking.

   [ko->ok] 2.1 X11 Window Type & Screen Strut Incompatibility on Wayland:
        - BUG: Original DockWindow used _NET_WM_WINDOW_TYPE_DOCK and X11 struts
          (_NET_WM_STRUT_PARTIAL). Wayland compositors reject X11 window types
          and struts, causing the dock to render as a normal centered window.
        - SOLVED: Re-engineered DockWindow.vala using gtk-layer-shell:
          initialized GtkLayerShell, set Layer.TOP, namespace "wayplank",
          and dynamic edge anchoring with exclusive zone screen negotiation.
   [ko->ok] 2.2 Forced X11 Backend Environment Overrides:
        - BUG: Runtime scripts forced GDK_BACKEND=x11 and QT_QPA_PLATFORM=xcb,
          crashing Wayland sessions lacking Xwayland.
        - SOLVED: Removed all forced X11 environment variable assignments,
          enabling native Wayland GDK and Qt backend initialization.
   [ko->ok] 2.3 Absence of Window Introspection on Wayland:
        - BUG: Wayland security model forbids global window tree inspection
          (XQueryTree), leaving the dock with zero visibility of running apps.
        - SOLVED: Implemented asynchronous procfs scanner in Matcher.vala
          periodically querying /proc/[pid]/cmdline and comm to identify
          running processes without X11 dependencies.
   [ko->ok] 2.4 Obsolete X11 Strut & Workarea Calculation Logic:
        - BUG: PositionManager.vala contained 400+ lines of X11 workarea, root
          window geometry, and multi-head Xinerama calculation code.
        - SOLVED: Purged obsolete X11 strut calculation routines in favor of
          GTK Layer Shell native anchor and margin property bindings.
   [ko->ok] 2.5 Missing Layer Shell Packaging Dependencies:
        - BUG: Generated Debian packages failed to install or run on minimal
          Wayland installations due to missing libgtk-layer-shell runtime.
        - SOLVED: Added libgtk-layer-shell0 and libgtk-layer-shell-dev to
          BuildDeb.sh control metadata and runtime package dependencies.

PHASE 3: MILESTONE V0.3.0 (2026-09-23) - HOVER STABILIZATION & EARLY KWIN
================================================================================
Summary: Inception of KWin D-Bus scripting bridge for live window tracking,
purged legacy BAMF and XInput VAPIs, and resolved mouse hover zoom glitches.

   [ko->ok] 3.1 Blind /proc Scanning Lacked Window Focus and Geometry:
        - BUG: Pure /proc scanning could not detect active/minimized window
          states or spatial window geometry, preventing running indicators.
        - SOLVED: Created KWinBridge.vala, establishing initial D-Bus connection
          to org.kde.KWin for live clientAdded and clientRemoved tracking.
   [ko->ok] 3.2 Mouse Crossing & Stuck Hover Zoom on Layer Shell Surfaces:
        - BUG: Cursor movement across dock surface failed to trigger parabolic
          icon magnification or caused icons to remain stuck in expanded state.
        - SOLVED: Rewrote pointer enter/leave/motion event handlers in
          DockWindow.vala and DockRenderer.vala with coordinate translation
          accounting for Layer Shell subsurface boundary offsets.
   [ko->ok] 3.3 Obsolete XInput 2, XFixes & BAMF VAPI Dependency Bloat:
        - BUG: Build tree was tied to vapi/xi.vapi (580 lines), libbamf3.vapi
          (171 lines), and legacy WindowControl.vala (484 lines).
        - SOLVED: Purged obsolete VAPIs and excised WindowControl.vala,
          replacing it with an abstracted stub interface for Wayland backends.
   [ko->ok] 3.4 Unreliable Application Pinning & State Binding:
        - BUG: Adding unpinned running apps to the dock corrupted launcher state
          because process IDs could not be mapped to .desktop launchers.
        - SOLVED: Implemented launcher lookup matching process command lines
          against desktop entry Exec= keys in ApplicationDockItem.vala.
   [ko->ok] 3.5 Layer Shell Subsurface Clipping During Zoom Animation:
        - BUG: Parabolic icon magnification clipped outer icon textures against
          the top/side window bounds of the layer surface.
        - SOLVED: Recalculated surface bounds and expanded layer-shell margin
          geometry to provide adequate headroom for 60 FPS zoom elevation.

PHASE 4: MILESTONE V0.4.0 (2026-09-24) - MODULAR BACKEND & INTELLIHIDE
================================================================================
Summary: Architected modular window management stack, deep KWin ECMAScript
bridge, real-time geometric Intellihide and Dodge engine, and app discovery.

   [ko->ok] 4.1 Monolithic Window Control Lacked Multi-Compositor Modularity:
        - BUG: Window management logic was coupled directly to temporary stubs,
          preventing clean extensibility to other Wayland compositors.
        - SOLVED: Created modular window stack in lib/Services: WindowBackend,
          WindowCapabilities, WindowInfo, WindowManager, and KWinBackend.
   [ko->ok] 4.2 Dock Overlapped Windows in Fullscreen and Dodge Modes:
        - BUG: Dock remained statically visible when application windows were
          maximized or moved over the dock zone.
        - SOLVED: Implemented HideManager.vala with real-time geometric
          intersection calculations for Intellihide, Dodge Active Window,
          and Dodge Maximized Window.
   [ko->ok] 4.3 Layer Shell Exclusive Zone Blocked Fullscreen Applications:
        - BUG: Fullscreen video (MPV, YouTube) left an empty gap at screen
          edge due to persistent Layer Shell exclusive zone reservation.
        - SOLVED: Dynamically toggled exclusive zone to 0 when dock autohides
          or dodges, restoring exclusive zone when permanently visible.
   [ko->ok] 4.4 Application Identity Resolution Mismatch on Wayland:
        - BUG: Wayland app_id strings frequently differed from binary names
          (e.g., org.gnome.Nautilus vs nautilus), causing duplicate icons.
        - SOLVED: Engineered ApplicationDiscovery.vala and
          ApplicationIdentity.vala with multi-tier heuristic launcher matching.
   [ko->ok] 4.5 Unmaintained Dynamic Docklet Plugin Crashes:
        - BUG: Legacy dynamic shared-library plugin architecture (lib/Docklets/)
          crashed on modern GCC due to ABI drift and missing symbol resolution.
        - SOLVED: Excised external dynamic plugin loader and introduced
          statically compiled SeparatorDockItem as clean architecture baseline.
   [ko->ok] 4.6 Dangling Signal Closures in KWin JavaScript Engine:
        - BUG: Reloading the dock left orphaned ECMAScript signal listeners in
          KWin, causing duplicate events and escalating memory consumption.
        - SOLVED: Added clean script registration lifecycle in KWinBridge with
          structured unload and de-registration routines.

        - SOLVED: Implemented persistent monitor configuration in

   [ko->ok] 5.2 Secondary Monitor Tooltip Placement Drift:

          and layout parameters in memory during active animation sequences.
   [ko->ok] 5.4 Legacy Unity Theme Artifacts & Incompatible CSS:
        - BUG: Obsolete Ubuntu Unity dock theme definitions caused Cairo render
          glitches and missing texture warnings.
        - SOLVED: Purged legacy Unity themes, bundled clean modern Arian themes

PHASE 6: MILESTONE V0.4.2 (2026-10-02) - MONOLITHIC DOCKLETS & POLISH
================================================================================
Summary: Suite of 8 monolithic built-in docklets (Trash D-Bus sync, Clock,
Battery, CPU, Show Desktop, MPRIS, Volume), folder stacks, anti-bounce,
zero-latency indicator dots, and --replace process lifecycle.

   [ko->ok] 6.1 Trash Docklet Lacked KDE Plasma / Dolphin D-Bus Sync:
        - BUG: Emptying or filling trash from Dolphin or terminal did not
          update docklet icon state; dragging files to trash failed.
        - SOLVED: Built native TrashDockItem (docklet://trash) with
          KWinTrashBridge listening to org.kde.KDirNotify, real-time item
          badges, animated bounce, and drag-and-drop trashing.
   [ko->ok] 6.2 Show Desktop Failed to Restore Hidden Windows:
        - BUG: Clicking Show Desktop minimized windows but second click failed
          to restore them to their original stacking order.
        - SOLVED: Implemented stateful two-way toggle in ShowDesktopDockItem
          caching hidden client UUIDs (wayplankDesktopHiddenClients) and
          restoring original focus on second click.
   [ko->ok] 6.3 Analog Vector Clock Aliasing at Arbitrary Scales:
        - BUG: Analog clock dial and hands rendered blurry or distorted on
          HiDPI or non-standard icon sizes.
        - SOLVED: Built ClockDockItem with pure Cairo anti-aliased vector
          dial face, tick marks, smooth sweeping second hand, and 1s ticks.
   [ko->ok] 6.4 Battery Monitor Hardware Query Failure:
        - BUG: Upstream battery code failed to discover modern sysfs battery
          nodes under Wayland.
        - SOLVED: Implemented direct /sys/class/power_supply/BAT* reader in
          BatteryDockItem with color-coded charge level capsules and bolt.
   [ko->ok] 6.5 CPU & Memory Monitor Lack of Real-Time Differentials:
        - BUG: Resource monitor displayed static or inaccurate load metrics.
        - SOLVED: Built CpuDockItem with live differential /proc/stat and
          /proc/meminfo parsing and dual circular Cairo vector gauges.
   [ko->ok] 6.6 Folder Stack Left-Click Hijacked Drag Mechanics:
        - BUG: Left-clicking a folder immediately popped up the stack menu,
          preventing users from dragging the folder to reorder or poof.
        - SOLVED: Restored standard left-click drag mechanics in FileDockItem
          (reorder/poof), animated bounce, and moved menu to right-click.
   [ko->ok] 6.7 Pinned Folder Drag & Drop Lacked Executable Permissions:
        - BUG: Dropping .desktop files into pinned folders produced files
          without executable bits (0644), preventing direct launching.
        - SOLVED: Enforced automatic chmod 0755 on dropped .desktop files and
          integrated GLib.AppInfo.launch_default_for_uri for document opening.
   [ko->ok] 6.8 Spurious Icon Bounce on Application Close:
        - BUG: Closing the last window of an app caused adjacent dock icons
          to bounce as if newly launched.
        - SOLVED: Filtered out client.deleted events in KWin bridge and
          isolated focus animation triggers in ApplicationDockItemProvider.
   [ko->ok] 6.9 CLI --replace Flag Missing from Option Table:
        - BUG: Launching "wayplank --replace" produced "Unknown option",
          preventing automated restart from scripts or desktop actions.
        - SOLVED: Registered --replace (and -r) in AbstractMain.vala GOption
          table with clean previous-instance termination (killall -q -9).
   [ko->ok] 6.10 Unthrottled Multi-Window Mouse Wheel Cycling:
        - BUG: Fast wheel scrolling over multi-window apps flooded KWin with
          focus events, freezing window switching.
        - SOLVED: Implemented rate-limited smooth scroll event translation
          (Gdk.ScrollDirection.SMOOTH) cycling windows forward and backward.
