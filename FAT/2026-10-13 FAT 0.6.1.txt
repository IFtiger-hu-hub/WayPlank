GNOME BUGS / NOTES:
 - BUG 1 (Squashed): Folder Launcher popup menu closed prematurely when cursor
   moved across gap towards menu.
   * Root Cause: Hovering off the item set HoveredItem to null, which triggered
     an immediate (0ms) dismissal.
   * Fix: Added 450ms dismissal grace window (DISMISS_DELAY = 450U) when moving
     towards popup across the gap; immediate dismissal only if hovering another
     dock item. Reduced gap to 4px.
 - BUG 2 (Squashed): Folder Launcher menu did not follow dynamic icon zoom
   elevation (overlapping magnified icons).
   * Root Cause: Base dock thickness was used instead of item visual elevation
     during zoom.
   * Fix: Restored 60 FPS dynamic elevation tracking via
     pm.get_visual_thickness_for_item(TargetItem) + GAP across all 4 positions
     (BOTTOM, TOP, LEFT, RIGHT).
 - BUG 3 (Squashed): Theme change rendered missing custom folder drawer icons as
   empty/blank cards.
   * Root Cause: Custom folder icon names stored in GIO metadata were not
     checked against newly selected desktop icon themes, falling back to empty
     application-default-icon.svg.
   * Fix: Added DrawingService.has_icon() and hooked on_icon_theme_changed() in
     DockItem/FileDockItem. When custom icon is missing in new theme, WayPlank
     falls back cleanly to 4-item preview stack while preserving GIO metadata on
     disk.
 - BUG 4 (Squashed): Empty folder drawers rendered blank trays.
   * Fix: When drawer contains 0 items, renders a clean centered default folder
     icon on the frosted tray.
 - BUG 5 (Squashed): Folder drawer bottom-left corner artifact (black
   horn/spike).
   * Fix: Corrected arc order in FileDockItem.draw_icon_fast (Math.PI_2,
     Math.PI).
 - IMPROVEMENT 6: Rich Units in Docklet Numeric Badges (°C, °F, %).
   * Root Cause: draw_item_count only accepted int64 count, rendering raw
     numbers without units (e.g. 24 instead of 24°C, 85 instead of 85%).
   * Fix: Added BadgeText property to DockItem and draw_item_badge() in
     DockTheme.vala supporting arbitrary UTF-8 text. Added °C/°F to Weather, and
     % to CPU (system pressure), Battery, Volume, Network (Wi-Fi), and
     Brightness docklets. Clean integer counts preserved for Ejector and App
     notifications.
 - BUG / COSMETIC 7: Docklet badges oversized (~50% of icon size) obscuring
   underlying icons.
   * Root Cause: Badge height hardcoded at 0.50 * icon_size, covering ~40% of
     icon area.
   * Fix: Scaled badge height down to ~34% of icon size (min 10px; ~16px on 48px
     dock, ~24px on 72px zoomed dock), saving over 50% surface area. Adjusted
     proportional pill width formula ((0.50 + 0.32 * chars) * height, clamped to
     78% icon width), reduced padding to 1.5px, and scaled Pango font size
     directly to available inner box height (min 7.0pt) for crisp, sharp, non-
     occluding badges.
