1. ICON & LAUNCHER MANAGEMENT

        Drag .desktop / app from menu/files onto dock
   [  ] 1.5 Drag-Off Removal (Poof):

   [  ] 1.6 Drag & Drop Onto Icon: Drag compatible file onto app icon to open it
   [  ] 1.7 Categorized Drag Bounding & Cross-Separator Pin/Unpin:
        - In Categorized mode, dragging Folders is strictly clamped within
          Folders section.
        - Dragging Docklets is strictly clamped within Docklets section.
        - Dragging Pinned Apps across the separator into Unpinned section unpins
          the application.
        - Dragging Unpinned Running Apps across the separator into Pinned
          section pins the application.
        - Dragging apps cannot cross left into Docklets/Folders or right into
          Trash.
        - Attempt to drag locked items (Preferences, Separator, Trash):
          drag cleanly aborts with zero GLib terminal warnings.
   [  ] 1.8 Folder Launcher Popup Menu (Cairo-Dock Style):
        - Left-click on a folder dock item toggles the Folder Launcher menu:
          BUG: The menu appear in the center of the screen.

          ("Keep in Dock", "Open in File Browser", "Preferences").
        - Menu is non-modal and non-grabbing (does not freeze dock or desktop).
        - Zoom Following: Dock icon zoom animation remains fluid (60 FPS); menu
          dynamically follows the icon's horizontal center and visual elevation.
        - Decoupled Bounce: Left-clicking triggers icon bounce animation while
          the menu remains rock-steady and decoupled from the bounce height.
        - Dark Tooltip Styling: Menu matches tooltip style (rgba(28, 28, 30,

        - Subfolder drill-down with back button navigation, launcher execution,

        - Auto-dismisses when hovering another dock item or on desktop leave.
   [  ] 1.9  First-Run Onboarding & Default Drawers:

          Media, Games/Utility), default pinned apps, and accordion defaults.
   [  ] 1.10 Universal 'Change Icon...' & Metadata Storage:
        - Right-click App -> 'Change Icon...': instant search, custom
          icon applies cleanly, 'Restore Default' restores original.
        - Folder drawers accept custom icons via GIO metadata.

   [  ] 3.1 None: Dock permanently visible, never hides
   [  ] 3.2 Autohide: Hidden by default, reveals when cursor touches screen edge
   [  ] 3.3 Intellihide (Intelligent):
        Window overlaps dock -> hides; moves away -> reveals
   [  ] 3.4 Dodge Active: Hides only if focused active window overlaps dock
   [  ] 3.5 Dodge Maximized: Hides only when a window is maximized
   [  ] 3.6 Window Dodge: Hides if any window (active or inactive) overlaps dock

          when Hide Dock is enabled (no longer disabled by legacy is_wayland check).
        - When ON, expands edge trigger zone to 5px for fluid cursor unhide.
        - Mouse touching edge unhides dock immediately.
   [  ] 3.8  Accordion Retention on Dock Hide/Unhide:
        - If dock closes (e.g. intellihide) and reopens before delay expires,
          drawer remains open.
        - Timer cancels upon cursor re-entry.

   [  ] 4.1 Empty Workspace Switch:

   [  ] 4.2 Occupied Workspace Switch:

   [  ] 4.3 Sticky Windows:

   [  ] 4.4 Dynamic Workspaces:
